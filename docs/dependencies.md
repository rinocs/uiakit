# Dependencies Milestone 1

The full Python versions are in `apps/runtime/requirements*.txt`; Go ones
in `apps/gateway/go.mod` with checksum `go.sum`. Locally verified toolchain:
Go 1.27.1 and CPython 3.13.16. Python code requires >=3.12.

No code from the frameworks mentioned in the specification has been copied. Haystack,
LlamaIndex, Langflow, Qdrant, Redis, and LiteLLM are not initial core dependencies.
SBOM CycloneDX and notice transitive are generated by `make release-inventory`
(`scripts/release.py`), with licenses from the metadata/lockfile and allowlist in
`tests/release/check_licenses.py`; the base image packages are analyzed
from Syft in the release pipeline. This table remains a summary, not an audit
complete legal. Check the weight license of the chosen model separately.

The current development environment does not allow external DNS or Docker sockets; the tests
HTTP uses injected resolvers and ephemeral local listeners. Docker builds and E2E
require an enabled environment. No dependencies have been replaced with stubs
in the production code.

M2: `packages/core` is a local package `uai-core==0.1.0`, depends only on
Pydantic. Backend build fixed to setuptools 84.0.0 (MIT). Runtime/CI/Docker
they install the package from the monorepo; development can use editable installation.
No new Go dependencies introduced for credentials, RBAC, and migrations.

M3 storage: `boto3==1.43.118` (Apache-2.0) is an **optional** dependency, pinned
in `apps/runtime/requirements-s3.txt` and installed in development/CI for testing.
The default core stack and runtime image do not include it; the S3 adapter
fails with `BlobStoreUnavailable` if package is missing. RustFS (test-only, `s3` profile, pinned image for digest) is used as
S3-compatible service in the `make storage-s3` fixture; it is not an addiction of
production.

M3 parsing: `pypdf==6.21.2` (BSD-3-Clause) and `defusedxml==0.7.1` (Python Software
Foundation License) are runtime dependencies for PDF and DOCX, pinned in
`requirements.txt` and in the pyproject runtime. They are not used for networking,
script or OCR; OCR/SQL/web/Git backends remain optional contracts.

Worker M3-06: `psycopg==3.3.6` and `psycopg-binary==3.3.6` (LGPL-3.0) are
worker process dependencies, installed in the `uai-worker` image and in
development for testing. The runtime and gateway don't matter to her; PostgreSQL
remains the only authoritative queue.

M3 embeddings: no new Python dependencies beyond `httpx` already pins; Ollama is
an optional service (Compose profile `local-ai`/`full`) and model weights
chosen have separate licenses. LiteLLM is not a core dependency: if used,
stays behind the OpenAI-compatible border.

M3 vector store: Qdrant 1.15.0 is an optional service (Compose profiles `rag`/
`full`, Apache-2.0), not published and not required by the core. The adapter uses
`httpx` already pinned; no mandatory Qdrant client.

M4-03 HTTP tools: `httpcore==1.0.9` (BSD-3-Clause) is declared directly because
HTTP transport uses a connection pool with a network backend pinned to the address
DNS validated. No additional services; secret headers are env references
files resolved at runtime and are not persisted or returned to the model. M6-04
does not introduce runtime dependencies: egress and rate limit only use standard libraries
(`urllib.parse`, sync, time); `opentelemetry-sdk` remains a dev dependency for the
telemetry test.

M6-07 release: No new runtime dependencies. `VERSION` is the source of the
SemVer version; `tests/release/check_release.py` checks that Python manifest,
npm, Composer and image tags match, that the Python requirements are pinned with
`==` and that the lockfiles (`go.sum`, npm, `composer.lock`) exist. `scripts/release.py
inventory` generates `sbom.cdx.json` (CycloneDX 1.5) and `THIRD_PARTY_NOTICES.md` from
transitive lockfile dependencies; `tests/release/check_licenses.py` applies
an SPDX allowlist and fails on `NOASSERTION`. The release pipeline uses Syft for
SBOM of source and images, Grype for high/critical vulnerabilities with fixes
available, and attach reports to the bundle without publishing packages or images.
The images produced have `0.1.0` tag, OCI version/revision/license label,
image ID and tar hash in `images.json`. SDK/plugin packages are prepared
with `npm pack`, wheel, Composer archive and Go source, without `npm publish` or
`composer publish`. First-party code is GPL-3.0-only; dependencies retain their own
licenses and corresponding redistribution obligations. The model weights remain
outside the software SBOM and require separate verification. Details in
[releases.md](releases.md).

The PHP SDK `composer.lock` is resolved with `config.platform.php=8.3.0` to
match CI. Symfony clock/translation are locked to the 7.4 line (PHP >=8.2),
not the 8.1 line that requires PHP >=8.4. Validate and install with
`/usr/bin/php8.3 composer validate/install` before release.
